# CeyNova Labs Homebrew tap

Formulae for tools from [CeyNova Labs](https://ceynovahq.com).

```sh
brew install ceynova-labs/tap/ceynox-watch
```

| Formula | What it is |
|---|---|
| [`ceynox-watch`](https://github.com/CeyNova-Labs/ceynox-watch) | See what a command really does on your machine: every program it starts, every host it talks to, every credential it touches. |

The formulae install the binaries published on each project's releases page and check them against the checksums recorded here.
